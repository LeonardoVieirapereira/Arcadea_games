Escolher arquivos

Formatos retrô suportados: GB, GBC, NES, SNES, Mega Drive, N64 e GBA. PSP: ISO/CSO pode ser reconhecido, mas depende do ambiente compatível.

ZIP não é extraído automaticamente. Selecione o arquivo de jogo em formato compatível, não um ZIP que contenha vários arquivos. Não importe executáveis de PC/Android esperando que rodem no navegador.

Como tornar um jogo visível para todos

  1. Crie um arquivo chamado games.json na mesma pasta do index.html.
  2. Adicione nele os títulos e URLs públicas de arquivos que você tem permissão para distribuir.
  3. Envie os dois arquivos para o repositório GitHub e aguarde o Pages publicar.
  4. Atualize o catálogo. As URLs precisam ser acessíveis por HTTPS e permitir o acesso pelo navegador (CORS quando aplicável).

Não coloque jogos comerciais ou arquivos de BIOS no site sem autorização para distribuí-los.

PSP no GitHub Pages: limitação importante

O núcleo PSP do EmulatorJS requer threads e SharedArrayBuffer. Isso normalmente depende dos cabeçalhos Cross-Origin-Opener-Policy e Cross-Origin-Embedder-Policy. O GitHub Pages não oferece configuração arbitrária desses cabeçalhos. Para PSP, use uma hospedagem que permita esses cabeçalhos e teste em navegador moderno. O HTML pode tentar iniciar o núcleo PSP, mas não consegue resolver essa limitação de hospedagem sozinho.
