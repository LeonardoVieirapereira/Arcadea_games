# Arcade Vault — Biblioteca Retrô

Site pessoal de jogos arcade com estética de fliperama dos anos 80, feito em HTML, CSS e JavaScript puro.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Clique em **JOGAR** em qualquer jogo.

Não precisa instalar dependências nem criar conta. O Google Fonts é opcional; se estiver sem internet, o site usa fontes alternativas.

## Jogos incluídos
- **Neon Snake** — cobrinha controlada por setas/WASD.
- **Brick Buster** — quebra-blocos com mouse ou setas.
- **Pixel Invaders** — nave, movimento e disparos.
- **Memory Match** — jogo da memória com cartas clicáveis.
- **Pocket Pong** — pong contra o computador.
- **Meteor Dodge** — desvie dos meteoros.

Os seis jogos são mini-jogos originais implementados no próprio projeto, não ROMs de terceiros. Assim, não dependem de emuladores ou arquivos comerciais.

## Recursos
- Pesquisa e filtros por categoria.
- Favoritos persistidos no `localStorage`.
- Contador de partidas e recordes locais.
- Efeitos sonoros opcionais gerados pelo navegador.
- Layout responsivo para celular e computador.
- Sem bibliotecas JavaScript externas.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz.
3. Abra **Settings → Pages**.
4. Em *Build and deployment*, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.
5. Salve e aguarde o link publicado.

## Privacidade
Favoritos, recordes e partidas ficam salvos localmente no navegador desse dispositivo. Limpar os dados do site pode apagar esse progresso.
